🤝 Autonomy model

🟢

T0 · Auto, quiet

Reads, searches, capture, logging words, adding tasks, memory

👀 Visible in the chat trace
🟡

T1 · Auto + notify

Create or move Wren-tagged calendar blocks, update Notion task status, file to the inbox

↩️ Undo button · Activity tray · morning digest
🟣

T2 · Ask first

Anything involving other people, events Wren didn't create, sending, deleting, bulk edits

📲 Push: Approve / Deny / Edit · expires in 48h
🔴

T3 · Never

Payments, credentials, sharing or permissions, deleting databases

🚫 The tool doesn't exist. Wren offers to draft instead.

An ambiguous match (more than one candidate) always escalates T1 to T2. Quiet hours run 21:30–08:00.
